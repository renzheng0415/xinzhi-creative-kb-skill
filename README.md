# 心智知识库：让你的智能体帮你找参考

把下面这句话复制给 WorkBuddy、Claude Code、Codex、Antigravity 等具有本机文件与执行能力的智能体：

> 请从 https://github.com/renzheng0415/xinzhi-creative-kb-skill 安装心智知识库技能，按 START_HERE.md 自动完成，并检查能否检索公司案例。

不用自己下载文件，不用写代码，也不用填写一长串配置。智能体会识别自己所属的应用，完成安装、准备文档读取工具，并测试能否查到公司资料。

## 接入后能做什么

- 读取你指定项目的标书、项目定位、基础资料和甲方要求，整理本次项目需要什么。
- 按业态、客群、出品类型和已有的画面标签，从公司资料里筛选参考。
- 给出案例、预览和出处，说明为什么适合、可以借鉴什么、哪些条件不同。
- 从公司 NAS 取回原件，整理参考清单，返回当前任务。具体图片或附件展示取决于所用应用。

例如：

> 读取我这个项目文件夹里的全部资料，先整理客户要求，再从心智知识库找 5 个适合的住宅定位和主画面参考。说明借鉴理由，附预览和原件。

## 使用条件

电脑需要连接公司网络，能打开 http://192.168.1.251:8798/ 。本仓库是安装工具，不包含公司的案例、原件或任何账号凭据。即使下载了安装工具，在公司网络之外也不能访问案例库。

安装完成后，智能体每次使用都会读取网站当前内容。公司新增案例完成入库后，下次检索就能看到，不需要重新安装。部分原素材目前只有目录索引；引用前仍应回看原件，不能把未提炼的图片或文档说成已经读完。

## 给智能体的安装入口

请阅读 [START_HERE.md](START_HERE.md)，再运行 `install.py`。用户只需发出上面的安装指令；客户端参数、依赖和验证由执行安装的智能体处理。

目前准备了 WorkBuddy、Claude Code、Codex、Antigravity App/IDE/CLI、DSH 和 Grok Build 的技能目录入口。客户端加载技能和附件展示仍需在当前安装环境验证，不能只凭文件复制完成就宣称所有功能已经接通。
